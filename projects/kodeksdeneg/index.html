Кодекс денег

Справочник о деньгах простым языком: долги, приставы, коллекторы, банкротство, личные финансы. 228 страниц и Android-приложение.

Открыть проект ↗

Задача

Дать людям понятные пошаговые ответы на денежные проблемы — и сделать так, чтобы их находили в поиске.

Результат

Бесплатный справочник без рекламы платных услуг: 228 страниц в индексе и мобильное приложение.

Решение

  • Контентная архитектура по ситуациям: «что делать по шагам», «что говорит закон», «куда обратиться».
  • Статичный сайт с упором на скорость и SEO: структура, перелинковка, разметка.
  • Android-приложение со всеми темами (192 темы в версии 1.1), распространение через RuStore и прямой APK.
  • Схема размещения, при которой сайт открывается из России без ограничений.
