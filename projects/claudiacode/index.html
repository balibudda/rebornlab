Claudia Code

Платформа донатов для стримеров: приём платежей, оповещения в эфире в реальном времени и свой Twitch-бот у каждого стримера.

Открыть проект ↗

Задача

Дать стримерам свою платформу донатов с оплатой картой и криптовалютой и мгновенными алертами на стриме.

Результат

Рабочая платформа с собственной базой данных, платежами и realtime-слоем.

Решение

  • SaaS на Next.js: кабинет стримера, страницы донатов, настройки алертов.
  • Платежи: ЮKassa и криптоплатежи (NOWPayments).
  • Realtime-оповещения в OBS через Pusher.
  • Персональный Twitch-бот у каждого стримера.
