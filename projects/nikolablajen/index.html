Никола Блажен

Платформа с AI-толкованиями: сайт, веб-приложение, Android-приложение, оплаты, аккаунты и SEO-машина на ~500 страниц.

Открыть проект ↗

Задача

Сделать продукт, который живёт сам: человек приходит из поиска, получает ценность от AI, возвращается каждый день и может заплатить — на сайте и в приложении.

Результат

Работающий продукт с живыми пользователями, приложением в RuStore и органическим трафиком из Яндекса и Google.

Решение

  • Веб-приложение (React + TypeScript) и Android-приложение из одного кода (Capacitor), PWA с push-уведомлениями.
  • AI-толкования через OpenAI с тщательно настроенными промптами и проверкой качества на тестовом наборе.
  • Вход по email-коду и через Яндекс, анонимный режим без регистрации, лимиты и защита от ботов.
  • Оплаты ЮKassa с серверной проверкой платежа, подписка «Премиум».
  • Генератор статичных SEO-страниц: значения карт, подборки, «карта дня» — около 500 страниц в карте сайта с разметкой schema.org.
  • Конвейер автопостинга: видео рендерятся в GitHub Actions и уходят в Telegram, YouTube и Facebook.
  • API переехал на собственный сервер, чтобы сервис стабильно работал из России.
