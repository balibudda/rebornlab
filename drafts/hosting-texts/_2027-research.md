# Рейтинг хостингов 2027 — исследование выдачи (19.11.2026)

## Запросы и подтемы в выдаче
- «рейтинг хостингов 2026/2027», «лучший хостинг», «топ хостингов» — общие списки ТОП-6…ТОП-12 с баллами.
- «лучший VPS», «как выбрать VPS по параметрам» — номинации («экосистема», «бюджетный старт», «железо за минимальный чек»), подбор vCPU/RAM под задачу (лендинг, бот, магазин, 1С), NVMe, KVM/OpenVZ/LXC, почасовая оплата, скрытые доплаты (IPv4, DDoS, бэкапы, лицензии Windows).
- «хостинг для 1С-Битрикс рейтинг» — отдельные топы виртуального хостинга и VPS под Битрикс, требования (у агрегатора версии PHP/MySQL противоречат друг другу в разных разделах), статус «рекомендуемый хостинг», BitrixVM/BitrixEnv, скрипт bitrix_server_test.php.
- «облачный хостинг рейтинг», «хостинг для интернет-магазина», «OpenCart VPS рейтинг», «хостинг для WordPress» — подборки по CMS и типу сайта.
- «дешёвый хостинг» — сортировка по цене, бесплатные тарифы.

## Конкуренты (что есть / чего нет)
- hostinghub.ru — каталог: категории по типу услуги, 15 CMS, типам сайтов, ОС, виртуализации, городам; балл = скорость+надёжность+цена+обслуживание; сами пишут, что оценки субъективные; FAQ про сервис и отзывы. Нет открытых сырых замеров из РФ, страницы по Битриксу с противоречивыми требованиями.
- vc.ru «Как выбрать VPS/VDS в 2026» — гайд по параметрам + 3 номинации; методики замеров нет, FAQ нет, ссылки-редиректы при обещании «без рефералок».
- vc.ru / dtf.ru ТОП-11, ТОП-13 (VPS универсальные, под сайты, под OpenCart) — списки с промокодами, помечены как реклама, без собственных измерений.
- dtf.ru «Лучшие хостинги для сайта 2026» — 6 позиций, рекомендации по типу проекта (визитка, магазин, портал, Битрикс), FAQ 8 вопросов (VPS vs виртуальный, NVMe/CPU/RAM, DDoS, перенос, тормоза, тест). Реклама, замеров нет.
- sostav.ru ТОП-10 — рекламный обзор (страница уже 404).
- websiteplanet — зарубежный, тесты на своих сайтах, к РФ мало применим.

Общий пробел: ни у кого нет регулярных одинаковых замеров из России без VPN; методика либо «мнение специалистов», либо отсутствует; рейтинги смешаны с партнёрскими ссылками без подписи; категории есть, но место внутри категории ничем не измерено.

## Факты для текстов 2027 (проверено)
- PHP (php.net/supported-versions): 8.2 — безопасность до 31.12.2026; 8.3 — до 31.12.2027; 8.4 — до 31.12.2028; 8.5 — до 31.12.2029.
- CA/B Forum SC-081v3: макс. срок публичного TLS-сертификата 200 дней с 15.03.2026, 100 дней с 15.03.2027, 47 дней с 15.03.2029.
- Реестр провайдеров хостинга РКН с 1.12.2023; не вошедшим в реестр с 1.02.2024 запрещено оказывать услуги хостинга в РФ.
- 1С-Битрикс: тестовый скрипт bitrix_server_test.php; «Проверка системы» и «Монитор производительности» в админке; BitrixVM (старые образы на CentOS 7, у которой поддержка закончилась 30.06.2024; есть BitrixVM 9).

## Наш угол (страница 2027 ≠ 2026)
2026 — общая таблица и «как выбрать хостинг» (57 вопросов). 2027 — рейтинг ПО КАТЕГОРИЯМ: виртуальный, VPS, облако, WordPress, Битрикс, магазин. Внутри категории — один и тот же замер (панель + DNS, 48 раз в сутки из РФ без VPN), без баллов «по ощущениям». FAQ — про выбор внутри категории, изменения 2027 (PHP, SSL 100 дней, реестр РКН), как читать рейтинги и отзывы, как сравнивать самому и через бота.
