3. Что мы делаем с данными

Сбор, запись, систематизация, накопление, хранение, уточнение, извлечение, использование, передача (предоставление доступа) лицам из раздела 5, блокирование, удаление и уничтожение — с использованием средств автоматизации. Данные не продаём, для рекламы третьим лицам не передаём, решений, порождающих юридические последствия, только на основе автоматической обработки не принимаем.

4. Проверка сайтов и письма владельцам

Сервис проверки сайтов (proverka.rebornlab.ru) автоматически просматривает открытые страницы сайтов организаций. Источники адресов сайтов — открытые данные (в том числе OpenStreetMap). Если находим нарушения, отправляем одно письмо на общий адрес организации, опубликованный на её сайте (например, info@…). Личные адреса сотрудников не используем. Повторных писем и рассылок нет. По ссылке в письме можно отказаться — адрес попадёт в список «не писать», и мы не напишем на него никогда.

6. Трансграничная передача

Часть сервисов из раздела 5 находится за пределами России, поэтому обработка включает трансграничную передачу персональных данных. Она выполняется на основании вашего согласия и в объёме, необходимом для целей из раздела 2.

7. Как мы защищаем данные

  • передача только по защищённому соединению (HTTPS);
  • доступ к данным — только у оператора, по ключам, без паролей в открытом виде; серверы закрыты от посторонних подключений;
  • платёжные данные карты не попадают на наши серверы;
  • запись содержимого полей форм в Вебвизоре отключена;
  • регулярное резервное копирование в зашифрованном виде;
  • данные удаляются по окончании сроков из раздела 2.
